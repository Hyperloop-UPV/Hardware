HL UPV H12 Board Template

Standard project scaffold for Hyperloop UPV H12 PCBs.

Includes project-local library tables pointing at ../../libraries/ (shared symbols and footprints at the repo root) and KiCad 10 defaults for design rules, ERC/DRC severities and BOM export.

Layout assumption

The template expects the project to live two directory levels deep relative to the repo root — e.g. H12/MyBoard/ — so that the library paths ../../libraries/... resolve to the repo's shared libraries. Adjust the library table URIs if you place the project elsewhere.

How to use

  1. Install the template once: Preferences → Configure Paths → User Templates, point at the templates/h12-board/ folder of this repo.
  2. Create a new project: File → New Project from Template → h12-board. KiCad copies the template and renames the files to your chosen project name; ${PROJECTNAME} inside the files is replaced automatically.
  3. Commit the new project folder under H12/<your-board>/ so library paths stay correct.
